目的: 直接在clion上开发能在android上跑的程序. 所以需要用到ndk. 先配置:

```
Settings->Build,Execution,Deployment->Toolchains
```

添加内容如下: 

```
Cmake: C:\Users\daily\MyFile\asset\sdk\cmake\3.22.1\bin\cmake.exe
BuildTool: 留空
C Compiler:  C:\Users\daily\MyFile\asset\sdk\ndk\29.0.13113456\toolchains\llvm\prebuilt\windows-x86_64\bin\aarch64-linux-android35-clang.cmd
C++ Compiler: C:\Users\daily\MyFile\asset\sdk\ndk\29.0.13113456\toolchains\llvm\prebuilt\windows-x86_64\bin\aarch64-linux-android35-clang++.cmd
Debugger: 留空
```

![](obsidian/attachments/Image_2026-05-27_10-38-08_qzhd2kym.wbf.png)


```
Settings->Build,Execution,Deployment->Cmake
```

为每一个平台都设置一个Cmake



其中Windows_Release, Windows_Debug 就是原来默认的两个改名而已. 

![](obsidian/attachments/Image_2026-05-27_10-46-46_ca1v1xc0.vwb.png)

Linux-Debug, Linux-Release 是复制默认的两个, 修改ToolChain为WSL. 

![](obsidian/attachments/Image_2026-05-27_10-42-55_y1tmlo1t.41j.png)

Android-Debug, Android-Release 是复制默认的两个. 修改ToolChain 为NDK.

然后Cmake Options填入: 

```
-DCMAKE_TOOLCHAIN_FILE=C:\Users\daily\MyFile\asset\sdk\ndk\29.0.13113456\build\cmake\android.toolchain.cmake
-DCMAKE_ANDROID_NDK=C:\Users\daily\MyFile\asset\sdk\ndk\29.0.13113456
-DANDROID_ABI=arm64-v8a
-DCMAKE_SYSTEM_NAME=Android
-DCMAKE_SYSTEM_VERSION=28
-DCMAKE_C_FLAGS=""
-DCMAKE_CXX_FLAGS=""
-DCMAKE_ANDROID_NDK_TOOLCHAIN_VERSION=clang
-DCMAKE_ANDROID_ARCH_ABI=arm64-v8a
```
